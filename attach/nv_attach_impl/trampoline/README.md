# trampoline for PTX code

- `default_trampoline.cu` is a template program, where the built-in trampoline for map operations comes from
- `default_trampoline.ptx` is generated by `nvcc` (`make` target) and embedded into `../trampoline_ptx.h`
- The `bpf_main` kernel in `default_trampoline.cu` is only a demo for the standalone `test` binary. It is stripped when generating `../trampoline_ptx.h`, since the real `bpf_main` comes from the compiled eBPF program and ptxas would otherwise reject the duplicate definition.
- Default architecture in `Makefile` is `sm_75` (CUDA 13.x no longer supports `sm_61`)
